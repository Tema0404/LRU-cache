# LRU cache

## *Description*
The project was created as part of a study of the work of the LRU cache

## *technologies used:*
- c++
- STL

## *program operation scheme*
The cache class contains methods for :
1. output of cache usage statistics
2. adding a pair to the cache
3. searching for a value by key
4. a friendly function for displaying the current cache scheme
